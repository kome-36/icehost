## Secrets 说明
- `ICEHOST_SERVER_URL`：服务器面板页地址
- `ICEHOST_COOKIES`：面板登录 Cookie（icehostpl_session 的值）
- `TG_BOT_TOKEN` / `TG_CHAT_ID`：Telegram 通知
